🏛️ 전국 공통 1회 배포 및 독립 운영 원리

본 시스템은 GitHub Pages에 단 1번만 배포해 두면, 전국의 어떤 학교 도서관이든 URL 파라미터(`?gas=클라우드URL`)를 통해 자기 도서관 데이터만을 독립적으로 안전하게 격리하여 운영할 수 있습니다.

📋 새 도서관 클라우드 연동 3단계
  1. sheets.new에 접속하여 새 스프레드시트를 만듭니다.
  2. [확장 프로그램] ➔ [Apps Script]를 누르고 아래 스크립트를 붙여넣은 뒤 [배포] ➔ [웹 앱]으로 배포합니다.
  3. 발급받은 웹앱 URL을 관리자 설정에 등록하면 우리 도서관 세팅이 끝납니다.
