꿈빛 (Ggumbit) 이용 가이드

스마트폰 홈 화면에 '꿈빛' 앱으로 설치하기

• 안드로이드 (크롬/삼성인터넷): 화면 상단의 [📲 지금 홈 화면에 앱 추가하기] 버튼을 누르면 원클릭으로 설치됩니다.
• 아이폰 (Safari): 하단 공유 버튼(⎋) ➔ [홈 화면에 추가]를 누르면 주소창 없이 진짜 앱처럼 구동됩니다.

🧭 구글 시트 초기 연동 5단계 요약

  1. STEP 01: [도서관 설정] ➔ [1. 구글 시트 연동]에서 [새 시트] 클릭 후 시트 이름 지정.
  2. STEP 02: 시트 상단 [확장 프로그램] ➔ [Apps Script] 열기 ➔ 기존 코드 전체 삭제 후 [스크립트 복사] 붙여넣기 및 저장(Ctrl+S).
  3. STEP 03: Apps Script 상단 함수 목록에서 testSystem 선택 후 [실행 ▶] ➔ [권한 검토] ➔ [고급] ➔ [이동(안전하지 않음)] ➔ [허용].
  4. STEP 04: [배포] ➔ [새 배포] ➔ 유형: 웹 앱, 실행 권한: '나', 액세스: '모든 사용자' 지정 후 배포 ➔ 생성된 웹 앱 URL 복사.
  5. STEP 05: 꿈빛 웹화면 STEP 04에 URL 붙여넣고 [연동 저장] ➔ [5대 탭 자동 구성] 클릭!
