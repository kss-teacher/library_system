1단계: 시트 생성 및 편집기 실행

새 스프레드시트 준비 및 Apps Script 진입

새 스프레드시트 생성

  • 주소창 입력: sheets.new 접속
  • 시트 제목 설정: 학교 도서관 명칭 입력
  • 데이터 분리: 학교별 독립 공간 확보

Apps Script 창 열기

  • 상단 메뉴: [확장 프로그램] 선택
  • 도구 실행: [Apps Script] 클릭
  • 새 창 열림: 전용 코드 편집 화면 진입

2단계: 스크립트 코드 복사 및 붙여넣기

웹앱에서 제공하는 백엔드 엔진 코드 장착

01. 1초 복사

웹앱 상단 설명서 내 복사 버튼 터치.

02. 기존 코드 삭제

편집기 기존 텍스트 전체 선택 삭제.

03. 붙여넣기 및 저장

Ctrl + V 붙여넣기 후 상단 디스크 저장.

3단계: 웹 앱 배포 핵심 설정

원활한 모바일 접속을 위한 배포 옵션 구성

가장 중요한 필수 확인 사항

웹 앱 액세스 권한: 모든 사용자 (Anyone)

배포 메뉴 선택

우측 상단 [배포] ➔ [새 배포] 클릭.

유형 지정

톱니바퀴 아이콘 ➔ 웹 앱 선택.

권한 오류 방지

'나만' 설정 시 모바일 연동 불가.

4단계: 구글 보안 경고 대응 및 승인

개인 스크립트 배포 시 표시되는 구글 표준 보안 절차

안심 가이드: 개인 제작 스크립트 배포 시 구글이 표시하는 정상 안내입니다 (바이러스·오류 아님).

01. 경고 확인

'확인되지 않은 앱' 정상 표시.

02. [고급] 클릭

좌측 하단 작은 [고급] 선택.

03. 이동 링크 클릭

[제목(안전하지 않음)] 이동 선택.

04. 최종 [허용]

스프레드시트 접근 권한 승인.
